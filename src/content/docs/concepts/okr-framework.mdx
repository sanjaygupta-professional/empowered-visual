# OKR Framework

## Concept Overview

OKRs (Objectives and Key Results) are the mechanism for giving empowered teams problems to solve rather than features to build.

```mermaid
mindmap
  root((OKR Framework))
    Objectives
      What we want to achieve
      Problems to solve
      Qualitative
    Key Results
      How we measure success
      Business outcomes
      Quantitative
    Principles
      Problems not features
      Outcomes not output
      Ambitious but achievable
```

## The OKR Barbell

```mermaid
flowchart LR
```
