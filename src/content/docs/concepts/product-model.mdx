# The Product Model

## Concept Overview

The Product Model is how strong product companies work—with technology as a core enabler and empowered teams solving problems.

```mermaid
flowchart TB
    subgraph Model["THE PRODUCT MODEL"]
        V["Product Vision<br/>🌟 Where we're going"]
        S["Product Strategy<br/>📋 How we'll win"]
        O["Team Objectives<br/>🎯 Problems to solve"]
        D["Discovery & Delivery<br/>⚙️ Teams empowered"]
        R["Business Results<br/>✓ Value delivered"]
    end

    V --> S --> O --> D --> R

    subgraph Enablers["ENABLERS"]
        L["Leadership"]
        C["Coaching"]
        T["Topology"]
    end

    Enablers -.-> Model

    style Model fill:#e3f2fd
    style Enablers fill:#fff3e0
```

## Old Model vs Product Model

```mermaid
flowchart TB
    subgraph Old["OLD MODEL ✗"]
        O1["Business decides what to build"]
        O2["Tech teams build it"]
        O3["Output measured"]
    end

    subgraph New["PRODUCT MODEL ✓"]
        N1["Business shares problems"]
        N2["Teams discover solutions"]
        N3["Outcomes measured"]
    end

    style Old fill:#ffcdd2
    style New fill:#c8e6c9
```

## Key Components

| Component | Description | Responsibility |
|-----------|-------------|----------------|
| **Vision** | Where we're going (3-10 years) | Product leadership |
| **Strategy** | How we'll get there | Product leadership |
| **Objectives** | Problems to solve | Leadership + Teams |
| **Discovery** | Finding solutions | Empowered teams |
| **Delivery** | Building solutions | Empowered teams |
